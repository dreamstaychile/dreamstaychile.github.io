# Sistema V1 de Contratos Dream Stay Chile
Reemplaza el contenido de `/ds-propietarios-7x4/` por esta carpeta.

Flujo acordado: revisar contrato tipo → datos propietario → una o varias propiedades → revisar/confirmar → enviar.

V1 es simple: el envío abre un correo dirigido a contacto@dreamstaychile.com. Dream Stay revisa los antecedentes, completa el contrato, genera/revisa el PDF, lo sube manualmente a la plataforma de firma y envía el enlace. Firma primero el propietario y luego Dream Stay. SLA: contacto en máximo 24 horas hábiles.
